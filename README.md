# Attendance Management System          

A desktop-based Attendance Management System designed to simplify and manage attendance-related records efficiently. The project includes the application source code, compiled build files, distribution package, and SQL database script.

## 📌 Project Overview

The Attendance Management System helps manage attendance records through a software application connected to a database. It is developed as a Java-based project using a structured development environment.

## ✨ Features

- Attendance record management
- Database integration using SQL
- Organized source code structure
- Application build and distribution files
- SQL script for database setup

*Note: The available features depend on the implementation in the source code.*

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Database:** SQL
- **Development Environment:** NetBeans project structure
- **Build System:** Based on the included project configuration

## ⚙️ Prerequisites

Before running the project, make sure you have:

- Java Development Kit (JDK)
- NetBeans IDE or a compatible Java IDE
- A compatible SQL database server, if required by the application
- The database configuration details used by the project

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/CodeHub-ui/Attendance-Management-System.git
```

### 2. Open the Project

1. Launch NetBeans IDE.
2. Select **File → Open Project**.
3. Choose the cloned `Attendance-Management-System` folder.
4. Wait for the project to load.

### 3. Set Up the Database

1. Open your SQL database management tool.
2. Locate the `attd_mng_sys.sql` file in the project directory.
3. Import or execute the SQL script using a compatible database server.
4. Verify the database and update the application's connection settings if necessary.

### 4. Configure the Database Connection

Check the source code for database connection settings. Update the database URL, username, password, and driver configuration according to your local environment.

### 5. Build and Run

1. Select the project in NetBeans.
2. Click **Clean and Build**.
3. Run the project using the IDE.

Alternatively, check the `dist/` directory for an existing distributable application, if available.

## 🔧 Troubleshooting

- **Project fails to build:** Verify that the required JDK and project libraries are installed.
- **Database connection fails:** Check the database server, connection URL, credentials, and JDBC driver.
- **Application does not start:** Review the IDE output for missing dependencies or configuration errors.
- **Database import fails:** Confirm that the SQL script is compatible with your database server.
